# Discrete BJT Logic Gates

A hardware-level exploration of digital logic using **NPN Bipolar Junction Transistors (BJTs)**.
---

##  Components
* **Transistors:** 2N2222 (NPN)
* **Resistors:** $10\text{k}\Omega$ (Base), $220\Omega$ (LED)
* **Inputs:** Push Buttons
